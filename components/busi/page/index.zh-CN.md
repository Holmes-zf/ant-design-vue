页面容器组件群：围绕「页面骨架」的五个容器组件 —— `PageBody`（主体容器，页头槽 + 内容区）、`PageBodyHeader`（页头横条）、`DetailPage`（页面级外壳：页头行 + 内容 + 页面底栏）、`DetailHeader`（页头行：左「返回 + 标题」｜右工具位）、`DetailContainer`（区块级容器，带本区块自己的底栏）。五个组件只负责布局与高度分配，不带业务样式，也不感知业务状态：页头内容、正文、底栏一律由插槽决定。

## 何时使用

- 需要一块「可选页头 + 内容」的主体区域时，用 `PageBody`（传不传 `#header` 决定页头是否渲染）。
- 详情页 / 表单页需要「返回头 + 内容 + 页面级底栏」的整页外壳时，用 `DetailPage`。
- 页头要「左侧返回 + 标题 + 副标题 + 标签，右侧页面工具按钮」的编排时，用 `DetailHeader`。
- 一个页面里有多个区块、每个区块各自要一条操作条时，用 `DetailContainer`。

## 组件选型

| 组件 | 角色 | 底栏 | 典型用法 |
| --- | --- | --- | --- |
| `PageBody` | 主体容器：页头 + 内容，尺寸可控 | 无 | tab 面板、卡片内的内容区 |
| `PageBodyHeader` | 页头横条（白底 / 60px / 左右 10px / 下间距 12px） | 无 | 放进 `PageBody` 的 `#header` 槽；页头只有一条工具条时也可单独使用 |
| `DetailPage` | 页面级外壳：页头行 + 内容 + 页面底栏 | 有（`#footer`，贴底常驻） | 详情页、表单页 |
| `DetailHeader` | 页头行：左「返回 + 标题 + 副标题 + 标签」｜右工具位 | 无 | `DetailPage` 内部已使用；个性化页头可单独使用 |
| `DetailContainer` | 区块级容器：内容 + 本区块底栏 | 有（`#footer`，`flow` / `fixed`） | 页面内分块，每块各自带操作条 |

## API

通用约定（全家族生效）：

- **高度上下文自适应，不需要开关**：宿主高度确定（tab 面板、弹窗体、定高卡片、已定高的页面外壳）时，内容区自己滚、底栏常驻列尾；宿主高度随内容时退化为整页滚动，底栏排在内容末尾。
- **底栏「有没有」只由插槽决定**：条件底栏把 `v-if` 写在 `<template #footer v-if="…">` 上，槽不存在即不留空，容器不感知任何业务状态。
- **尺寸口径**：`width` / `height` 接受数字（按 `px`）与纯数字串（按 `px`）；带单位或 CSS 关键字（`100%`、`auto`、`inherit`…）原样透传。
- **主题变量**：底色 / 阴影 / 层级 / 底栏高度取业务 CSS 变量（`--bg-color-white`、`--form-footer-shadow`、`--z-index-fixed-footer`、`--form-footer-height`），未接入业务主题时以浅色基线回落。
- **样式覆盖**：需要改容器内部样式时，用「祖先类 + 目标类」（配合 `:deep()`）覆盖，不要与容器基础规则拼同特异性。

### PageBody

页面主体容器：可选页头横条 + 弹性内容区（内容区纵向撑满剩余高度）。

| 参数   | 说明                                            | 类型             | 默认值 | 版本 |
| ------ | ----------------------------------------------- | ---------------- | ------ | ---- |
| width  | 宽度，数字 / 纯数字串按 `px` 处理               | string \| number | `100%` |      |
| height | 高度，默认撑满父级；需要随内容长高时传 `'auto'` | string \| number | `100%` |      |

#### PageBody 插槽

| 插槽名称 | 说明                                                             | 版本 |
| -------- | ---------------------------------------------------------------- | ---- |
| header   | 页头横条内容（渲染在 `PageBodyHeader` 内）；不传时整条页头不渲染 |      |
| default  | 内容区                                                           |      |

### PageBodyHeader

页头横条，只提供默认规格与一个默认插槽，没有 props。默认规格：白底、最小高 60px、左右内缩 10px、与下方内容间隔 12px，内容 `flex` 换行并垂直居中。需要其它形态（灰底、紧凑高度等）时用「祖先类 + `.page-body-header`」覆盖。

#### PageBodyHeader 插槽

| 插槽名称 | 说明                                     | 版本 |
| -------- | ---------------------------------------- | ---- |
| default  | 页头内容（标题、标签、按钮等，自由排布） |      |

### DetailPage

页面级外壳：页头行 + 内容 + 页面级底栏（一个页面一个脚）。自身不声明高度，随内容；需要定高时在页面侧写 `.detail-content { height: … }`。

| 参数       | 说明                                          | 类型     | 默认值 | 版本 |
| ---------- | --------------------------------------------- | -------- | ------ | ---- |
| showHeader | 是否渲染页头行                                | boolean  | `true` |      |
| title      | 标题                                          | string   | -      |      |
| subTitle   | 副标题                                        | string   | -      |      |
| back       | 返回键点击回调；不传时按路由 / 浏览器历史回退 | function | -      |      |

> 返回键恒渲染（`a-page-header` 以回调是否存在判定），`back` 只决定点击行为。

#### DetailPage 插槽

| 插槽名称    | 说明                                                      | 版本 |
| ----------- | --------------------------------------------------------- | ---- |
| tags        | 标题行内的标签位                                          |      |
| headerRight | 页头右侧工具位                                            |      |
| default     | 页面内容                                                  |      |
| footer      | 页面级底栏（贴底常驻，通常放 `FormFooter`）；不传则不渲染 |      |

### DetailHeader

页头行：左「返回 + 标题 + 副标题 + 标签」｜右「工具位」。本组件是页头横条的唯一子节点，左右分配靠自身 flex 完成，白底 / 高度 / 内边距等外观由宿主决定（`DetailPage` 内已适配）。

| 参数     | 说明                                          | 类型     | 默认值 | 版本 |
| -------- | --------------------------------------------- | -------- | ------ | ---- |
| title    | 标题                                          | string   | -      |      |
| subTitle | 副标题                                        | string   | -      |      |
| back     | 返回键点击回调；不传时按路由 / 浏览器历史回退 | function | -      |      |

#### DetailHeader 插槽

| 插槽名称    | 说明             | 版本 |
| ----------- | ---------------- | ---- |
| tags        | 标题行内的标签位 |      |
| headerRight | 右侧工具位       |      |

### DetailContainer

区块级容器：内容 + 本区块自己的底栏。只做纵向排布，不加背景、圆角与内外边距。

| 参数 | 说明 | 类型 | 默认值 | 版本 |
| --- | --- | --- | --- | --- |
| footer | 本区块底栏形态：`flow` 流内列尾（宿主定高即常驻，随内容则排在末尾）/ `fixed` 常驻浮层 | `flow` \| `fixed` | `flow` |  |

#### DetailContainer 插槽

| 插槽名称 | 说明                     | 版本 |
| -------- | ------------------------ | ---- |
| default  | 区块内容                 |      |
| footer   | 本区块底栏；不传则不渲染 |      |

#### 注意

> `footer="fixed"` 配合 `FormFooter` 的 `fixed` 形态使用，容器会自己给内容层留出浮层高度；浮层锚定页面祖先，**同一页面只放一个 `fixed` 容器**。多块各自要底栏时用默认的 `flow`。
