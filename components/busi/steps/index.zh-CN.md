节点式步骤条：`StepsBox` 按节点列表横向排布，节点之间用「三圆点」连接，当前节点显示完成图标、其余节点显示序号。内容只由 `steps` 决定，不接受插槽。

## 何时使用

- 展示单据/任务的流转节点（已到达、当前所在节点），节点带标题与时间等副标题时。
- 需要「显式指定哪些节点点亮」（跳节点、部分节点未走过）的场景。

## 组件选型

| 组件           | 角色                                             | 典型场景                |
| -------------- | ------------------------------------------------ | ----------------------- |
| `StepsBox`     | 容器：节点列表 + 点亮控制（`value` / `current`） | 单据 / 任务流转节点展示 |
| `Step`         | 单节点：图标位 + 标题 + 副标题（内部件）         | 由 `StepsBox` 渲染      |
| `StepIcon`     | 圆形图标壳：点亮态换主色（内部件）               | 由 `Step` 渲染          |
| `StepSpotIcon` | 节点间三圆点连接件，纯装饰（内部件）             | 由 `StepsBox` 渲染      |

## API

### StepsBox

| 参数 | 说明 | 类型 | 默认值 | 版本 |
| --- | --- | --- | --- | --- |
| steps | 节点列表，每项 `{ title, description }` | Array&lt;{title, description}> | `[]` |  |
| value | 显式点亮：命中的索引点亮（传 `[]` = 一个都不点亮）；**只要传了就以它为准，忽略 `current`** | number[] | - |  |
| current | 顺序点亮：`0..current` 全部点亮；仅未传 `value` 时生效 | number | - |  |

- 越界与非整数索引会被丢弃（不会出现整条静默熄灭）。
- 当前节点 = 点亮集合中的最大索引；没有点亮项时不显示完成图标。
- 节点宽度固定，节点较多时请放在可横向滚动/可滚动的容器里（如 `ScrollBox`）。

### Step

单节点（内部件，由 `StepsBox` 渲染；一般不需要单独使用）。

| 参数        | 说明                   | 类型             | 默认值  | 版本 |
| ----------- | ---------------------- | ---------------- | ------- | ---- |
| title       | 标题                   | string           | -       |      |
| description | 副标题（如节点时间）   | string           | -       |      |
| text        | 图标位默认内容（序号） | string \| number | -       |      |
| active      | 是否点亮               | boolean          | `false` |      |

#### Step 插槽

| 插槽名称 | 说明                                                 | 版本 |
| -------- | ---------------------------------------------------- | ---- |
| default  | 图标位内容，覆盖 `text`（`StepsBox` 用它传完成图标） |      |

### StepIcon

圆形图标壳（内部件，由 `Step` 渲染）。

| 参数   | 说明                                     | 类型    | 默认值  | 版本 |
| ------ | ---------------------------------------- | ------- | ------- | ---- |
| active | 是否点亮（点亮 = 主色底 + 主色同族投影） | boolean | `false` |      |

#### StepIcon 插槽

| 插槽名称 | 说明                       | 版本 |
| -------- | -------------------------- | ---- |
| default  | 圆内内容（序号或完成图标） |      |

### StepSpotIcon

节点之间的三圆点连接件（内部件，纯装饰，`aria-hidden`，由 `StepsBox` 渲染）。

| 参数    | 说明                                 | 类型   | 默认值 | 版本 |
| ------- | ------------------------------------ | ------ | ------ | ---- |
| current | 当前节点索引；`-1` 表示无点亮项      | number | -      |      |
| value   | 自身索引（连接点排在该索引节点之前） | number | -      |      |

> 点亮规则为 `current >= value`：连接点严格跟随它指向的节点，不存在「早一步」的半态。
