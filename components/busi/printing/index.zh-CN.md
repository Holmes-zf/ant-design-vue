打印容器：把默认插槽的内容搬进独立 iframe 后调起浏览器打印，因此只打印这块内容、不打印整页。纸张按 A4、页边距 0，打印件与页面其余部分完全隔离。

## 何时使用

- 需要只打印页面上的一块内容（单据、标签、面单等），而不是整页时。
- 打印件需要按页分块、稳定分页与纸张边距时。

## API

### PrintingBody

组件没有 props，内容与打印时机均由插槽和组件实例方法决定。

| 参数 | 说明 | 类型 | 默认值 | 版本 |
| --- | --- | --- | --- | --- |
| printing | 组件实例方法：内容、图片、字体就绪后调起打印。打印源不可用时 reject（如组件未挂载） | () => Promise&lt;void> | - |  |

#### PrintingBody 事件

| 事件名称    | 说明                             | 回调参数   | 版本 |
| ----------- | -------------------------------- | ---------- | ---- |
| after-print | 打印结束（含用户取消打印）后触发 | function() |      |

#### PrintingBody 插槽

| 插槽名称 | 说明                                                   | 版本 |
| -------- | ------------------------------------------------------ | ---- |
| default  | 打印件内容；一页一块，块与块之间加 `break-after: page` |      |

#### 注意

- 打印件样式写在 `scoped` 的 `<style>` 里即可（组件会把这些规则注入 iframe）；**非 scoped 的全局样式不会注入**，不要依赖父页面的定位与尺寸。
- 主题 CSS 变量会一并搬进 iframe，业务样式直接用 `var(--xxx)`。
- 打印完成后 iframe 内容会被清空，不会残留上一次的打印件。
